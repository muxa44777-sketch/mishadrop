# MishaDrop — онлайн без запуска сервера игроком

Backend запускается один раз на хостинге. Игроки только открывают HTTPS-сайт.

## Архитектура
Браузер → HTTPS сайт → WebSocket `/ws`

Комната хранится на backend в памяти. Код комнаты состоит из 6 символов.

## Ссылка комнаты
После создания комнаты игра формирует ссылку:
`https://ВАШ-ДОМЕН/#case-battle=ABC123`

Игрок может открыть её напрямую — код автоматически подставится.

## Render
В репозитории уже есть:
- `Dockerfile`
- `render.yaml`
- `requirements.txt`

Создайте Web Service из репозитория и дождитесь Deploy. Никакого Python на компьютерах игроков не требуется.

Примечание: если бесплатный тариф выбранного хостинга не предоставляет постоянное хранилище, онлайн-комнаты всё равно работают, но SQLite-данные аккаунтов могут сбрасываться после перезапуска. Для постоянных аккаунтов используйте постоянную БД/диск.
