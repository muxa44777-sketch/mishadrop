ОДНОРАЗОВАЯ НАСТРОЙКА ДЛЯ ВЛАДЕЛЬЦА

1) Размести папку проекта в GitHub.
2) На Render создай Web Service из репозитория.
3) Выбери Docker runtime (определится из Dockerfile).
4) Deploy.
5) Получишь HTTPS-сайт.

ПОСЛЕ ЭТОГО:
Игроки не запускают server.py.
Игроки не устанавливают Python.
Игроки просто открывают сайт.

Создать комнату → получить код/ссылку → друг открывает ссылку → играет.
