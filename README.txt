MishaDrop — ONLINE CASE BATTLE

Что изменено:
• Игрокам больше не нужно запускать server.py, Python или Docker.
• Case Battle автоматически подключается к /ws на том же HTTPS-домене.
• Хост создаёт комнату и получает код.
• Можно отправить другу код или ссылку вида #case-battle=ABC123.
• Друг открывает ссылку — код подставляется и комната подключается автоматически.
• В комнате 2–6 игроков.
• Все игроки открывают один и тот же кейс.

ВАЖНО:
Сам backend всё равно должен быть один раз размещён в интернете. Этот архив уже содержит Dockerfile и render.yaml для публикации. После публикации игрокам ничего запускать не нужно.

Публикация:
1. Загрузите проект в GitHub.
2. Создайте Web Service на Render из этого репозитория.
3. Render использует Dockerfile автоматически.
4. После выдачи HTTPS-адреса откройте его — игра сама подключится к WebSocket.
5. Отправляйте друзьям ссылку на игру или ссылку комнаты.

Локальный LAN-запуск больше не нужен для онлайн-режима.
